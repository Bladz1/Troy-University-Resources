## Chuyên môn và kỹ năng

### Hướng chuyên môn
- **Human–Computer Interaction (HCI) / User-Centered Design**
- **Product Design, Illustration, Prototyping**
- **Web/Mobile Application Development**

### Công nghệ và kỹ năng
- **Programming**: C/C++, Java, JavaScript
- **Web/Mobile**: React, React Native, Node.js, Express, REST API
- **Database**: MySQL, SQLite
- **Authentication/Web backend**: session-based authentication, JWT, bcrypt
- **Design/HCI**: needfinding, user research, low-/mid-fidelity prototyping, heuristic evaluation
- **Tools**: Git, GitHub, Figma

## Dự án và hoạt động học thuật

### H2T Electronic Store — AC4150E Human–Machine Interaction
- **Thời gian**: Học kỳ 2024.1
- **Thành viên**: Nguyễn Thu Hương (20210423), Bùi Hạnh Trang (20210851), Nguyễn Thị Thanh Hằng (20213570)
- **Vai trò**: **Product Design — Illustration, Prototyping**
- **Nội dung**: Xây dựng và đánh giá trải nghiệm người dùng cho một cửa hàng điện tử.
- **Nguồn**: [HMI project repository][hmi-project] · [AC4150E tại SEEE][ac4150e]

### E-shop Web & Mobile Application
- **Thời gian**: 06/2024–09/2024
- **Nội dung**: Phát triển hệ thống e-commerce có web frontend, mobile app và backend.
- **Công nghệ**: React, React Native, Node.js/Express, Axios, MySQL
- **Nguồn**: [Repository e-shop][eshop-project]

### Task Manager — IT4409 Web Technologies and e-Services
- **Thời gian**: Học kỳ 2025.2
- **Nội dung**: Ứng dụng quản lý công việc có đăng ký/đăng nhập, CRUD task, tìm kiếm, lọc, sắp xếp và dashboard trạng thái.
- **Công nghệ**: HTML/CSS/JavaScript, Node.js, Express, SQLite, JWT, bcrypt
- **Nguồn**: [Repository Task Manager][task-manager] · [IT4409][it4409]
